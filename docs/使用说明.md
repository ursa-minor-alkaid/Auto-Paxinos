# Paxinos 图谱自动测量工具：使用说明

本说明面向日常使用，介绍程序启动、界面操作、结果解读与常见问题。

所需的 python 依赖库已包含在 `PaxinosMeasure.exe` 中，无需额外安装。

## 一、功能概述

程序从《Paxinos and Franklin's The Mouse Brain in Stereotaxic Coordinates（第五版）》
示意图 PDF 中读取指定核团的绘图范围，输出以下结果：

- 核团在切片上的 ML（内外侧）与 DV（背腹）范围、面积、质心
- 以 bregma 为原点的注射坐标 `x(ML) / y(AP) / z(DV)`
- 该处脑表面高度，以及自脑表面起算的进针深度
- 带 0.5 mm 网格的核团标注图与结果 json

默认计算单侧坐标。

## 二、启动程序

1. 双击 `PaxinosMeasure.exe` 即可，无需安装 Python 或任何依赖。
2. 程序启动会把内置的运行环境解压到临时目录，等待数秒属正常现象。正常退出时会删除临时文件，若异常退出则需要手动进入目录删除。
   1. 本程序的临时目录名称：`%AppData%\Local\Temp\_MEIxxxxxxx`
3. 图谱 PDF 不随程序分发，需要在界面上指定路径。若把 PDF 放在程序同目录的
`resources` 文件夹内并命名为 `Paxinos脑图谱(第五版)-示意图.pdf`，程序启动时会
自动填入该路径。

## 三、界面说明

界面分为参数区（上部）、操作按钮区（中部）、日志区与预览区（下部）。

| 控件 | 说明 |
| --- | --- |
| 图谱 PDF | 示意图版 PDF 的完整路径，可用「浏览…」选择 |
| PDF 页码 | 目标切片在 PDF 中的页码，从 1 开始，（就是 PDF 本身的页码，不是 figure 数，是等于图上 Figure 号加 6） |
| 核团缩写 | 与图上标签完全一致（注意，是大小写敏感的），如 `AD`、`MD`、`AVDM` |
| 输出目录 | 结果写入位置，留空则使用程序同目录的 `output` 文件夹 |
| 运行模式 | 见下表，日常使用选「核团测量」 |
| 高级参数 | 一般无需修改，详见后文 |

**运行模式**：

| 模式 | 作用 |
| --- | --- |
| 核团测量 | 计算指定核团的坐标，输出标注图与 json，最常用 |
| 标定 + 轮廓 + 核团 | 依次执行标定、轮廓极值与核团测量，信息最全 |
| 仅标定 | 只检验页面标定质量，打印零点与拟合残差 |
| 轮廓极值 | 打印切片最高点、最低点与中线处脑表面高度 |

高级参数：

| 参数 | 默认值 | 说明 |
| --- | --- | --- |
| 渲染 dpi | 900 | 分割用的渲染分辨率，核团很小时可提高到 1200 |
| 窗口半径 mm | 0.8 | 标签周围的取样范围，标签离核团较远时加大 |
| 最小面积 / 最大面积 mm² | 0.01 / 1.5 | 候选区域面积筛选范围 |
| 列出候选区域 | 关 | 打印窗口内全部候选区域，便于人工核对 |
| 只看不保存 | 关 | 只打印结果，不写图片与 json |

参数改动会记录到 `%APPDATA%\PaxinosMeasure\config.json`，下次启动自动带出。

## 四、操作流程

1. 在「图谱 PDF」中填入或选择图谱文件
2. 填入 PDF 页码，例如 Figure 37 对应第 43 页
3. 填入核团缩写，例如 `AD`
4. 运行模式选择「核团测量」
5. 点击「开始测量」，进度条滚动期间界面保持可用
6. 测量完成后查看日志区文字结果与预览区的标注图
7. 点击「打开输出目录」查看生成的文件

若第 6 步的日志中提示未找到标签或区域异常，参考第七节处理。

## 五、结果解读

以第 43 页、核团 `AD` 为例，日志区输出形如：

```text
标定: X0=391.54 pt  YR0=21.10 pt  YB0=421.68 pt  MM=69.08 pt/mm
核团 AD  第 43 页  (Bregma -0.71 mm, Interaural 3.08 mm)
  [left] ML -0.94 .. -0.49   DV_bregma 2.61 .. 3.15   area 0.081 mm2   质心 (ML -0.70, DVb 2.84)
        注射坐标（以 bregma 为原点）: x(ML)=-0.70  y(AP)=-0.71  z(DV)=2.85 mm
        该处脑表面 DV_bregma 0.30，自脑表面起算深度 2.54 mm
```

各行含义：

- **标定**：页面标尺与图谱毫米之间的换算关系。`X0` 为中线零点，`YR0` 为 bregma
  零点，`YB0` 为内耳零点，`MM` 为每毫米对应的 PDF 点数
- **ML 范围**：核团在内外侧方向上的左右边界，负值为中线左侧
- **DV_bregma 范围**：核团在背腹方向上的上下边界，以 bregma 颅顶平面为 0，向下为正
- **area**：核团绘图区域的面积
- **质心**：区域的几何中心，注射坐标即由它换算得到
- **注射坐标**：`x(ML)` 为距中线距离，`y(AP)` 为切片的 bregma 值，
  `z(DV)` 为距 bregma 平面的深度
- **自脑表面起算深度**：从该 ML 处的脑表面到质心的距离，用于判断进针深度

## 六、输出文件

写入输出目录的文件有两类：

| 文件名 | 内容 |
| --- | --- |
| `nucleus_<缩写>_p<页码>_<left/right>.png` | 核团区域着色图，叠加 0.5 mm 网格与外接框 |
| `measure_<缩写>_p<页码>.json` | 标定参数、两侧区域范围、质心、注射坐标与候选列表 |

标注图中红色为选中的核团区域，蓝色矩形为外接范围，纵向红线与横向绿线为
0.5 mm 网格。预览区自动显示最近一次运行生成的图片。

## 七、常见问题

**提示「页面中未找到缩写标签」**

页码或缩写有误。核对页码是否为 Figure 号加 6，缩写是否与图上标签完全一致
（区分大小写，含空格或数字的标签需原样填写）。

**提示「窗口内没有合适大小的连通域」**

取样窗口或面积范围不合适。可逐步加大「窗口半径 mm」，或放宽「最小面积 / 最大面积」。

**某一侧面积明显偏大**

核团边界存在未画出的缺口，导致区域与相邻结构连通。勾选「列出候选区域」重新运行，
在日志中查看候选列表，用「最大面积」排除连通的大区域，或改取相邻区域后人工修正。

**标签画在核团外部**

少数核团的标签带引线、位于核团之外，自动选择可能选错区域。勾选「列出候选区域」，
结合候选列表的坐标与面积人工指定正确值。

**结果与人工读数略有出入**

差异通常在 0.02 mm 以内，来自标尺数字中心与刻度线之间存在约 1 pt 的系统偏差。
该偏差已在标定中通过刻度栅格吸附校正，剩余差异与人工在图上读数的不确定度同量级。

**杀毒软件报警**

单文件打包的程序容易被启发式引擎误报，属常见现象。可将程序加入信任列表。

## 八、适用范围与精度

- 仅适用于示意图版 PDF。染色图版是照片位图，无法按颜色与连通域分割
- 标定不确定度约 ±0.02 mm，与人工读数差异在同一量级
- 面积与质心描述的是绘图边界，不等同于组织学边界。作图与统计时以范围与质心为准
- 程序假定核团在图上为封闭区域。边界未画全时结果不可靠，需按「常见问题」处理
